# Source and asset attribution

This repository contains project code and a technical report by Junhao Zhang. It uses Amazon ESCI relevance judgments, SQID representations, FAISS, scikit-learn, XGBoost, LightGBM, PyTorch, Sentence Transformers, Hugging Face Transformers, FastAPI and Streamlit. External libraries, datasets and model weights retain their own terms.

The architecture image was supplied for the project report. Product titles/images displayed by the demo come from the configured catalog; no product dataset or checkpoint is redistributed in this source package.
