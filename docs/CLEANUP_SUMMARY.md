# Engineering cleanup

The export has one production implementation and a small offline research package. Weekly delivery names have been replaced with modules describing their function. Model/index files are external and unchanged.

Removed from the new export:

- Duplicate Week7 core/service versions, A0/A1 branches and compatibility adapter chains.
- Cached-query replay endpoints, replay tokens and old blocked-encoder fallback classes.
- Colab packaging/launch helpers, generated notebook payloads and local path discovery variants.
- Performance observers, port-rebind recovery runners, cleanup/quarantine instrumentation and abandoned five-repeat orchestration.
- P1/P2 and targeted optimization branches that were evaluated but not adopted.
- Duplicate model forward functions, unused imports/local variables, temporary outputs, bytecode and environment folders.
- Bundled checkpoints, dataset tables, relevance labels, private paths and duplicated LaTeX/font packages.

Retained:

- Approved free-text encoder path, exact Fusion Top100, Prepared28, original scaler/ListNet and stable product-key ordering.
- One bounded dispatcher with the original queue/deadline/LRU settings.
- English FastAPI/Streamlit demo and actual-field product display.
- Essential BM25/TF-IDF, pointwise/LambdaMART/ListNet, feature groups, scoped metrics and the separate projection experiment.
- Explanatory comments at precision-sensitive reductions, missing-image fallback, tie boundaries, worker isolation and timeout/shutdown behavior.
- Small automated tests, portable config examples, exact asset hashes, regression evidence and the technical report.

No historical experiment was deleted, rewritten or relabelled. This is the clean engineering source directory for GitHub; original experiment provenance remains available in the local archive. No remote repository was created or uploaded during cleanup.
